# Wimeloo — AGENTS.md

## Grundsätze
- Spiel für 5-Jährige ohne Lesepflicht: große Symbole, gesprochene Hilfen, direkte Touchaktionen, keine Zeitdruck-/Streakmechanik.
- Offline zuerst; keine Tracker, Werbung, Käufe, Konten oder Netzwerkanfragen.
- Browser-Entwicklermodus nur bei explizitem `?dev=1` oder `Ctrl+Shift+D`; im Android-WebView deaktivieren.
- Spielstand nicht brechen: Android Paket `de.sternenbaby.app` und `sternenbaby.state.v1` sowie appassets-Origin bleiben erhalten.
- Minispiele modular halten. Für neue Handlungen nachvollziehbare Animationen ergänzen.
- Keine privaten Signierdaten, Passwörter, Token oder Nutzer-Spielstände ins öffentliche GitHub.
- Nie Branch-Regeln deaktivieren, Main nur via PR; Ausnahmen nur mit autorisierter Bypass-Berechtigung.
- Vor Releases Tests, APK-Signatur und Android-Device-Verhalten prüfen.
